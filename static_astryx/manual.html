DocWise Archive AI — User Manual

Arabic/English OCR, folder indexing, smart filing, search, and RAG answers.

Start

  1. Double-click C:\Path\To\docwise-community\start.bat.
  2. Open http://127.0.0.1:8120.
  3. Keep the terminal window open.

OCR Status

Open Settings. Confirm Tesseract and Arabic OCR are available. Languages should include ara, eng, and osd.

Upload

Go to Upload / Folders, choose PDFs/images/Office/text files, then click Upload + Index. Supported: PDF, images, DOCX/DOC/DOCM, XLSX/XLS/XLSM, PPTX/PPT/PPTM, TXT/MD/CSV/JSON/RTF.

Folder Access

Paste a folder path like C:\Path\To\Documents\Scans, choose Recursive/Watch/Scan now, then click Add Folder. Original files are not moved.

Search

Use Library. Search Arabic or English, e.g. فاتورة الكهرباء, عقد الإيجار, DEWA invoice.

Ask AI / RAG

Use Ask AI. Example questions: كم قيمة آخر فاتورة؟, وين عقد الإيجار؟, Find all invoices from DEWA.

Document Viewer

Click a document card to see preview, OCR text, summary, source path, smart filing suggestion, and reindex/open buttons.

Smart Filing

Copy to Smart Filing copies files to data\archive\TYPE\YEAR. Originals stay untouched.

PDF shows ??????

Some Arabic PDFs expose broken embedded text. DocWise now detects this and OCR-renders the page. For old documents, open the file and click Reindex.
