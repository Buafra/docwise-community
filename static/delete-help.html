Deleting Documents

Option 1 — Remove from Index

This removes the document from DocWise search/RAG only. The original PDF/image stays on your computer.

Option 2 — Delete File + Index

This permanently deletes the original file from disk and removes it from DocWise. Use carefully.

Steps

  1. Open Library.
  2. Click the document.
  3. Click Remove from Index or Delete File + Index.
  4. Confirm the warning.
